## 1. What is Unary Classification?

**Goal**: Given a concept (e.g., "Car"), predict which other concepts it should be a subclass of (e.g., "Car ⊑ Vehicle").

**Example**: 
- Input: `Car`
- Output: `Car ⊑ Vehicle` (True/False)

**Purpose**: Learn to predict subclass relationships in ontologies using graph neural networks.

### Step 2: Forward Pass
```python
# For each concept pair (Car, Vehicle):
def forward(car_features, vehicle_features, graph):
    # 1. Get node embeddings
    car_emb = self.layers[0](car_features, graph)
    vehicle_emb = self.layers[0](vehicle_features, graph)
    
    # 2. Combine features
    combined = torch.cat([car_emb, vehicle_emb], dim=1)
    
    # 3. Final prediction
    prediction = self.layers[2](combined)
    return torch.sigmoid(prediction)  # Probability between 0-1
```

## 8. Why This Works

1. **Graph Structure**: Captures relationships between concepts
2. **Embeddings**: Learn semantic similarities
3. **RGCN**: Propagates information through the graph
4. **Training**: Learns patterns from positive/negative examples
5. **Prediction**: Applies learned patterns to new concept pairs

## 11. Key Differences: Unary vs Binary Templates

### Unary Template (UT) Rules:
```python
# Structure: body=[?] or body=[concept], head=[?] or head=[concept]
# Examples:
"body=[?], head=[LiquefiedGasTankerShip]"           # ? ⊑ LiquefiedGasTankerShip
"body=[OffshoreAnchorage], head=[?]"                 # OffshoreAnchorage ⊑ ?
"body=[Ramp], head=[?]"                             # Ramp ⊑ ?
```

**Characteristics:**
- **Single variable** (`?`) in either body or head
- **Simple subsumption** relationships
- **One-to-one** concept mapping
- **1,218 rules** in s1 dataset

### Binary Template (BT) Rules:
```python
# Structure: body=[?, concept1, concept2...], head=[?, concept1, concept2...]
# Examples:
"body=[?], head=[?, TrafficLight]"                   # ? ⊑ ? ⊓ TrafficLight
"body=[?], head=[?, DeckCargoShip, PalletizedCargoShip]"  # ? ⊑ ? ⊓ DeckCargoShip ⊓ PalletizedCargoShip
```

**Characteristics:**
- **Multiple variables** (`?`) and concepts
- **Complex intersection** relationships
- **Many-to-many** concept mapping
- **206 rules** in s1 dataset

### Statistical Comparison:
| Metric | Unary Template | Binary Template |
|--------|----------------|-----------------|
| **Rule Count** | 1,218 | 206 |
| **Complexity** | Low | High |
| **Variables per Rule** | 1 | 2+ |
| **Concepts per Rule** | 1-2 | 3+ |
| **Learning Difficulty** | Easier | Harder |
